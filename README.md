# 📖 Overview

The PromptVerse Server powers the backend of the AI Prompt Sharing & Marketplace Platform. It provides secure REST APIs for authentication, prompt management, payments, reviews, bookmarks, analytics, and role-based access control.

---

# ✨ Features

- JWT Authentication & Authorization
- Role-Based Access Control
- Prompt CRUD Operations
- Prompt Approval & Moderation
- Bookmark & Review APIs
- Stripe Payment Integration
- Analytics APIs
- MongoDB Aggregation
- Secure Environment Variables
- RESTful API Architecture
